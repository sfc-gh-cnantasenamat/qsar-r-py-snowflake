# Bioinformatics and Cheminformatics on Snowflake

Companion projects for building bioinformatics, cheminformatics, and computational drug discovery workflows on Snowflake.

| Folder | What it contains | Guide |
|---|---|---|
| [`r-python-drug-discovery/`](r-python-drug-discovery/) | End-to-end R and Python QSAR drug discovery pipeline with Python notebooks for ChEMBL bioactivity curation, an R container service on Snowpark Container Services for molecular potency modeling and Model Context Protocol serving, a multipage Streamlit in Snowflake application, and a Cortex Agent with semantic views, Cortex Search, and evaluation fixtures | [Build R and Python Powered Drug Discovery Apps and Agents on Snowflake](https://github.com/sfc-gh-cnantasenamat/sfguide-build-r-python-drug-discovery-apps-and-agents) |
